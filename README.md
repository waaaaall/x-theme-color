# X Theme Color Changer

X（旧Twitter）のテーマカラーを自由に変更できる Chrome 拡張機能です。

## 機能

- **カラーカスタマイズ**: X（Twitter）のベース色を好きなカラーに変更
- **直感的なカラーピッカー**: スムーズな色選択と即時のリアルタイムプレビュー
- **高速・低負荷**: 軽量な DOM 監視とスタイル先行注入により、チラつき（FOUC）やブラウザの負荷を防止
- **Grok の非表示**: Grok ドロワーなどの関連 UI を自動で非表示化

## インストール

1. リポジトリをクローン
   ```bash
   git clone https://github.com/waaaaall/x-theme-color.git
   cd x-theme-color
   ```

2. Chrome で `chrome://extensions/` を開く

3. 右上の「デベロッパーモード」を有効化

4. 「パッケージ化されていない拡張機能を読み込む」をクリック

5. クローンしたフォルダ（`x-theme-color`）を選択

## 使い方

1. X（Twitter: `x.com` / `twitter.com`）にアクセス
2. 拡張機能アイコンをクリック
3. カラーピッカーでテーマ色を選択（リアルタイムに即座に反映されます）

設定は自動でローカルストレージに保存されます。

## ファイル構成

```text
├── manifest.json    # 拡張機能の設定（Manifest V3）
├── content.js       # テーマ色のスタイル生成・注入スクリプト
├── popup.html       # ポップアップ UI
└── popup.js         # ポップアップ制御ロジック
```
